# Observability & Monitoring - Hands-On

## Overview

This repository documents my hands-on learning and practical exploration of **Observability and Monitoring** using Prometheus, Grafana, and Datadog.

The objective is to understand how monitoring systems collect metrics, visualize system performance, configure alerts, identify issues, and help maintain the reliability and availability of applications and infrastructure.

## Tools & Technologies

| Tool | Description |
|---|---|
| Prometheus | An open-source monitoring and alerting toolkit used to collect, store, and query time-series metrics. |
| Grafana | An open-source analytics and visualization platform used to create dashboards and visualize metrics from different data sources. |
| Datadog | A cloud-based observability platform for monitoring infrastructure, applications, metrics, logs, and system performance. |

## Key Concepts

- **Monitoring:** Tracking system health and performance using metrics, dashboards, and alerts.
- **Observability:** Understanding a system's internal state through metrics, logs, traces, and other telemetry data.
- **Metrics:** Numerical measurements such as CPU utilization, memory usage, request rates, and response times.
- **Dashboards:** Visual representations of metrics that help analyze system behavior and performance.
- **Alerting:** Automatically notifying the relevant people when configured conditions indicate a potential issue.
- **Troubleshooting:** Investigating metrics and monitoring signals to identify and resolve problems.
